# touhan

iOSアプリ「登録販売者 合格予測（非公式）」の公開情報（サポート・プライバシーポリシー・利用規約）を管理するリポジトリです。GitHub Pages（`main` ブランチの `/docs`）で公開しています。

- サポート: https://taaaaho.github.io/touhan/
- プライバシーポリシー: https://taaaaho.github.io/touhan/privacy.html
- 利用規約: https://taaaaho.github.io/touhan/terms.html

ページの文言は `scripts/build_pages.py` で管理しています。編集後に `python3 scripts/build_pages.py` を実行してください。

本アプリは個人開発の非公式アプリであり、厚生労働省・都道府県その他の団体とは提携・協力・監修関係はありません。

ソースコードは非公開リポジトリ（`touhan-code`）で管理しています。
